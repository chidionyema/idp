# __NAME__

Scaffolded by `estate-execute ui.scaffold --name __NAME__` on the estate UI kit (crew#694). Astro,
React islands, Tailwind v4, static output for Cloudflare's free tier.

- `src/site.config.ts` is the brand. `src/styles/global.css` imports the kit and declares nothing.
- `npm run guard` runs the kit's purity and contrast guards; `ui.review` runs them plus the weight budget.
- Pages compose the kit's templates (`Landing`, `Catalogue`, `Detail`, `Checkout`, `Account`, `Docs`, `ErrorPage`, `Empty`).
