# The home page speaks plain English

Date: 2026-09-01

## Status

Accepted.

## Context

The founder read the portal home page and could not tell what a "door" was. The
page counted 47 of them. A word we invented forced him to ask, and an investor
reading the same page would have to ask too. The home page also grouped every
company, product and tool under one band, which reads as one company when there
are two.

## Decision

The home page names things in plain words. A "door" is now a sign-in page, and
the page says so. Hermes and Prospector sit under Products; mumchimp is the one
company. Every title and description on the page is a word the founder did not
have to ask about. A test holds the page to this: the words on the page come
from one reviewed list, and a new invented word fails the build.

## Consequences

Anyone reading the home page understands it without asking. Renaming a thing
means changing the reviewed list, which is one small change with a test on it.
