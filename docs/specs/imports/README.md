## The direction in one paragraph

An estate that knows what exists, discovers what is missing, investigates what is uncertain, tests
what it believes, explains what it knows with evidence, acts within governed boundaries, and learns
from verified outcomes. Retrieval and the Oracle supply evidence; memory preserves it; Research and
Science challenge it; verification keeps it accountable to reality. Every execution leaves a trace
(AEI) that can be inspected, compared and visualised. Compose what exists; never add a second layer
(AGENTS.md section 6).

## Rules for every agent

1. Search origin/main and live lanes, not only your checkout; report how far behind main you are.
2. Query with the founder's words verbatim (Oracle, Gortex, ContextPlan, Science, AEI), then expand.
3. Name the sources you consulted and the ones that failed. "Exhaustive" is not a claim you can make.
4. Before proposing anything new, show the existing component you checked and why it does not cover it.
5. For every item state: specified, implemented, deployed or operating.
6. If a route fails, take another route and finish.
