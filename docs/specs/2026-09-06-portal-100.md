## 0. Contract

The portal is graded on what the founder experiences, proved by commands and drills — never on look-and-feel assertions (R53). Eight lanes, each with a 100-clause. Score = lanes at 100 / 8, re-measured weekly, published to the collector.

**Freshness contract (the systemic fix):**
- Every receipt the portal reads carries `measured_at` (ISO) and `interval_s`. Producers touched first: estate-state, science-facts, cluster-health, reports index.
- Panel contract in `backstage/packages/app/src/modules/home/`: every panel renders `measured_at` as age ("3h old"); stale beyond `2 × interval_s` ⇒ degraded style + one line: "This is stale — pipeline `<name>` is red: <link to run>"; empty ⇒ says why and what happens next.
- Implementation point: extend `useHealthchecks.ts`, `useReports.ts`, `useEstate.ts` (all already fetch-shaped) to surface age; a shared `<Freshness since interval>` component in `modules/home/visuals.tsx` so no panel hand-rolls it.

**100-clause:** `bin/portal-freshness-drill` fails when any founder panel renders stale-as-live; drill runs hourly and its receipt lands in the collector. Verify: the four workflows green; drill red→green on an injected stale fixture.

## Lane 3 — Tiles that prove they work (P1, week 2)

- `bin/door-probe` (new): hourly; for every `founder-surface` Component's `links:` in the catalog, GET with timeout; expect 2xx/3xx/401/403 (auth-expected); emit `door.state{entity, url, code, latency_ms}` to the collector. (The 2026-09-06 manual probe — 32/32 alive — is the baseline and the fixture set.)
- Tiles (`Tools.tsx`, `DoorGrid.tsx`): state dot + probe age from the receipt; dead door ⇒ tile says why ("refused since 09:14 — pipeline: <link>").
- `bin/catalog-links-check` extended: a door must have a URL **and** a green last probe (fail-closed when the probe could not run — fence_enforcement_gate rule).

**100-clause:** kill one door (fixture), tile shows dead within the hour, drill receipt proves it; CI refuses a PR adding a door with no probe coverage.

## Lane 4 — Design system, not polish (P1, weeks 2–4)

- Split `EstateHome.tsx` (1,170 lines) into composed panels under one contract: `{title, meaningLine, state, measuredAt, action}`. Panels live in `modules/home/panels/`; the page composes.
- Panel contract enforced by a unit test shape (`*.test.tsx` per panel, existing convention) + a lint rule: no page-level bespoke CSS outside `modules/theme` (stylelint custom rule or AST check in `scripts/`).
- Playwright visual-regression (config exists: `backstage/playwright.config.ts`) wired into `.github/workflows/ci.yml` over the six founder pages, animations disabled, structure-level assertions only (R53). axe pass per page.

**100-clause:** creating a new founder page = composing panels with zero new CSS (proved by building one demo page in the lane PR); visual suite green in CI on main.

## Lane 5 — One design language (P2, weeks 3–4)

- Stock pages (Docs, Create, Search, settings) either adopt the estate shell or leave the founder nav. Default decision (LAW 23, smaller road): park them off-nav; keep `/docs` reachable via entity pages only; restyle later only if the founder misses them.
- Search: one box over entities + docs + reports (`plugin-search` collators; reports collator new but small).

**100-clause:** founder nav contains only estate-styled pages (visual suite proves); a search for a known report title returns it.

## Lane 6 — Speed with budgets (P2)

- `test:lighthouse` exists (lhci). Set budgets per founder page: LCP ≤ 2.5 s behind SSO, TTI ≤ 3.5 s; catalog list pages paginated server-side (default page size 50); entity fetch caching in `useEstate.ts` (currently refetches per mount).
**100-clause:** lhci budget assertions enforced in CI; a PR blowing the budget goes red.

## Sequencing

Week 1: Lane 1 (fires + freshness contract) and Lane 2 (the five; sitting booked day 1). Week 2: Lane 3; Lane 4 starts. Weeks 3–4: Lane 4 lands; Lane 5. Lanes 6–8 after, one PR each. Every lane is one PR with its 100-clause as the merge gate (R41: strict on main).

- Lane 7 depends on Voice Gate phases 0–2 (prospector repo) — portal lane lands only after its benchmark is green; until then portal copy is frozen to human-edited strings.
