### What live source actually implements and fails to guarantee
- Existing `bin/estate-fleet` on main supports JetStream publish `send`, `broadcast`, `directive`, pull `inbox`, ephemeral Core NATS `watch`, `refuse`, `status`, and apparent ACK. Existing tests attempt a real throwaway NATS instance when the binary is present; no evidence here of successful cross-host authenticated production operation.
- Current `ESTATE_AGENT` is a self-declared environment string. `inbox --ack` publishes `applied` after mere delivery, `--pipe` equates process exit 0 with application, `refuse` accepts arbitrary sequence ID. `status` reads self-authored ack-subject data.
