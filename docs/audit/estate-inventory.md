### Why the middle column is not work

- **BootVolume** — the OKE worker pool makes these with its nodes
- **CustomerDnsZone** — OCI private DNS for a managed VCN
- **DnsResolver** — OCI private DNS for a managed VCN
- **DnsView** — OCI private DNS for a managed VCN
- **Instance** — a worker node from the managed pool
- **LoadBalancer** — answered by the cluster for a Service of type LoadBalancer
- **PrivateIp** — assigned to a managed vnic
- **PublicIp** — assigned to a managed node or load balancer
- **Vnic** — attached by the worker pool when a node comes up
- **Volume** — the block-volume CSI driver makes one per persistent claim

Those are recreated by whatever owns them when the estate is rebuilt. What is *not* recreated is the data on them, which is why `bin/idp-estate-backup` exists.
