## How to read this

- A timeout event is an assistant entry whose content is exactly `Request timed out`. The phrase inside a longer message is a quotation and is not counted.
- `attempt_s` is the attempt that worked; `caller_wait_s` is what the caller waited,
  retries included. The gap between them is the retries, and the retry count is reported
  too. The front's cloud-first wait sits inside the attempt: the front asks the cloud
  first and only then the laptop, and the cloud that answers 400 (it does not carry the
  founder's Claude model) cost the caller the whole wait.
- No prompt, no answer and no credential from any transcript is in this directory.
