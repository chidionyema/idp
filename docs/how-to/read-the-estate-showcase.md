# How to read the estate showcase

Demo: `ESTATE_CODE=~/dev/code bin/estate-showcase`

`docs/SHOWCASE.md` is the estate graded against the buyer's-engineer bar (crew#474). Read it
top to bottom; the order is the priority.

1. **The bar.** Three counts. ELITE is what a buyer may inspect; GAP is what they would find;
   BLIND is what nobody has measured yet. BLIND is not ELITE.
2. **Gaps, loudest first.** One row per entity that fails, with the annotation and value that
   decided it. `estate/last-status=signal 1` is a launchd job whose last run exited 1;
   `estate/dirty=50` is a checkout with 50 uncommitted files. The fix is the row.
3. **Standards not yet live.** Rows of `crew/docs/STANDARDS.md` whose status does not start
   with "live".
4. **Elite.** Everything that passed, with the reason.

The grades come from `bin/estate-showcase`, the rules are in its `grade()` function, and the
page is regenerated by `bin/catalog-render` after every inventory. A hand edit is refused by
`bin/estate-showcase --check`.
