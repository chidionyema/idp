# Onboarding: `idp-reasoning-gateway-hook`

This is the name on disk (`bin/idp-reasoning-gateway-hook`, a symlink to
`bin/reasoning_gateway_hook.py`) that `.claude/settings.json` invokes as the `Stop` hook. Full
onboarding -- commands, ledger location, and what it deliberately does not do -- lives at
[`how-to/onboarding/reasoning_gateway_hook.py.md`](reasoning_gateway_hook.py.md); this page exists
so the invoked name itself resolves to a page, matching every other `idp-*` entry point here.
