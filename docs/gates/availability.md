# Gate: ha

*`availability` · docs/reference/policy/availability-standard.md · planes: ci*

Every surface the founder can open survives losing one node, and so does every fail-closed admission webhook -- losing one of those costs not a hostname but the cluster's ability to apply anything, its own repair included

This page is generated by `bin/idp-gate-demo` from `rules.yaml`. The output below is what the gate itself printed when the generator ran it; it is not a description of what the gate does.

## Run it yourself

```bash
python3 bin/idp-availability-gate
```
