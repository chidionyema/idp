# Gate: main-green-gate

*`main-green-gate` · founder 2026-09-17 · planes: session*

A new branch is never pushed when main CI is red: every branch drawn from a broken main inherits its failures, and agents that continue opening PRs compound the pile-up rather than fixing the root cause. The gate is BLIND (exit 2, not exit 1) when the GitHub API is unreachable -- a fence a correct machine cannot satisfy is an outage (LAW 38).
