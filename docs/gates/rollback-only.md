# Gate: rollback

*`rollback-only` · W3.2 · planes: ci*

A pull request rolls one workload back only when every changed line is a newTag: whose value that same file has already carried on origin/main; a tag never on main is a forward deploy and waits, and a change that edits anything but a tag is refused -- the prior footprint is proved from history, never assumed from age

This page is generated by `bin/idp-gate-demo` from `rules.yaml`. The output below is what the gate itself printed when the generator ran it; it is not a description of what the gate does.
